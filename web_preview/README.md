# Luna AI Web Preview

这是一个独立的静态网页版 UI 预览，用于快速查看 Luna AI 移动端新界面的大致视觉效果和交互感觉。

## 文件

- `index.html`：页面结构
- `styles.css`：深色渐变、玻璃态卡片、聊天气泡、输入栏、设置弹窗等样式
- `app.js`：前端模拟交互

## 如何查看

直接用浏览器打开：

```text
web_preview/index.html
```

如果在电脑本地，也可以进入 `web_preview` 目录后用任意静态服务器打开，例如：

```bash
python3 -m http.server 8080
```

然后访问：

```text
http://localhost:8080
```

## 已模拟的功能

- 聊天与生图合并入口
- 顶部快捷卡片：聊天 / 生图 / 看图
- 设置弹窗
- API 配置状态显示
- 输入“画一张...”自动模拟生图
- 画笔按钮强制下一条按生图处理
- 模拟图片上传分析附件
- 模拟聊天打字机回复
- 模拟生成图片卡片
- 清空对话
- Toast 提示

## 注意

这是纯静态 UI 预览，不会真实调用 AI API，也不会真实上传图片或保存图片。真实功能仍在 Flutter App 中实现。
